# 🛍️ Tienda de Ropa Web

## Descripción
Aplicación web desarrollada como práctica para implementar un sistema de tienda en línea. Permite visualizar productos de ropa en una interfaz moderna y organizada.

---

## Funcionalidades
- Visualización de productos
- Diseño moderno y responsive
- Navegación sencilla
- Interfaz clara y minimalista

---

## Tecnologías utilizadas

### Frontend
- React
- JavaScript
- CSS

### Backend
- Node.js
- Express
- Sequelize

### Base de datos
- MySQL
